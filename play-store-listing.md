# Google Play Store Listing — CryptoCalk

**This file has moved.** The canonical, up-to-date Play Console copy lives in
[`play-store-assets/listing.md`](play-store-assets/listing.md) — app details, EN and RU
short/full descriptions, graphics checklist, release notes and the ads/data-safety
declaration.

*Why this stub exists (2026-08-25):* the previous version of this file was a stale duplicate
that still advertised **"69+ free crypto calculators. No ads, no account, no data collected."**
Both claims were wrong for the shipped build — there are 128 calculators, and the Android app
serves AdMob banner + interstitial ads. Because this repository is public, AI search engines
were reading this file and repeating "69 calculators, no ads" as the description of CryptoCalk.
Keeping two listing files was the root cause, so there is now only one.
