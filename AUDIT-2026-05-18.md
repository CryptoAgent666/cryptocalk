## Critical Findings & Fixes

### 1. ❌ → ✅ /compare/ had 0 Schema.org JSON-LD

**Issue**: SCH-1. count=0, SCH-3. parse OK=0/0
**Fix**: Added 3 schemas to `src/pages/compare.astro`:
- BreadcrumbList (2 items)
- CollectionPage (`@id`, `dateModified` full ISO 8601)
- ItemList (12 popular comparison pairings)

### 2. ❌ → ✅ All 20 pages missing .gov E-E-A-T citations

**Issue**: EAT-1. Gov sources = 0 on every page (no irs.gov/sec.gov/cftc.gov/etc.)
**Fix**: Added `CATEGORY_SOURCES` map to `LocalizedCalculatorPage.astro` — injects category-specific authoritative source block before FAQ on all 1,242 localized calc pages:

| Category | Sources |
|---|---|
| tax-reporting | IRS Virtual Currency FAQ, IRS Notice 2014-21, HMRC Cryptoassets Manual |
| mining | IRS Digital Assets, US EIA electricity rates |
| defi-yield | IRS Digital Assets, SEC DeFi Statement (Peirce 2021) |
| trading-tools | CFTC Bitcoin, SEC Investor Alerts |
| investment | SEC Investor.gov, US Treasury Tokenization, IRS Digital Assets |
| profit-loss | IRS Topic 409 (Capital Gains), IRS Digital Assets |
| gas-fees | Etherscan Gas Tracker, Federal Reserve Payment Systems |
| converters | CoinGecko API, Federal Reserve FX Rates |

Heading localized: `Authoritative sources` / `Fuentes autorizadas` / `Fontes oficiais` / `Resmi kaynaklar` / `आधिकारिक स्रोत` / `Авторитетные источники`. Links use `rel="noopener nofollow"`.

### 3. ⚠️ False positive — BUG-9. float precision `0.105263`

**Issue**: trailing-stop-loss-calculator SSR HTML contains `0.105263` (Position quantity).
**Analysis**: Default state 10,000 USD / 95,000 USD BTC = 0.10526315789... → `.toFixed(6)` = `"0.105263"`. **Intentional**, 6 decimals appropriate for crypto qty.
**Action**: No fix — false positive.

### 4. ⚠️ False positive — BUG-1. raw i18n key `zapper.xyz`

**Issue**: wallet-net-worth-calculator content has `zapper.xyz` which regex flagged as `word.word` pattern.
**Analysis**: `zapper.xyz` is a real DeFi wallet tracker URL, not an i18n key leak.
**Action**: No fix — false positive.

### 5. ⚠️ Non-actionable — CSP header missing on ALL pages

**Issue**: SEC. CSP: ❌ MISSING (20/20 pages)
**Analysis**: Plesk shared hosting doesn't allow CSP injection at server level. Adding via `<meta http-equiv="Content-Security-Policy">` in HTML works for some directives but not `frame-ancestors` etc. Out of scope for this audit.
**Action**: Documented for future infrastructure migration.

### 6. ⚠️ Non-actionable — HTTP-2. Slow time (3 pages)

**Issue**: 3 pages had >2s response (4901ms on /tr/depin-kazanc-hesaplayici/)
**Analysis**: Cold-cache first hit on Plesk nginx. Subsequent requests cached.
**Action**: Variable — not consistent enough to flag.
